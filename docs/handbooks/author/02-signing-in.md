# 2. Signing in

## The login screen

Adventure Builder has no self-service sign-up — an **Admin** creates your
account for you. Once you have a username and password, go to the app's
address and you'll land on a login form headed **"Adventure Builder"**, with
username and password fields.

- Enter your credentials and submit the form.
- If either field is wrong, the page reloads with an error state on the
  form — try again.
- There's no "forgot password" link on this screen; if you're locked out,
  ask your Admin to reset it.

## Where you land after signing in

Adventure Builder sends you straight to the dashboard for your highest
role:

| Your role | You land on |
|-----------|--------------|
| Admin | The admin dashboard |
| Author (no Admin) | **Author Dashboard**, headed *"Author Dashboard - Create your stories here"* |
| Player only | **Your Adventure Library** |

As an Author, the dashboard is intentionally small — one heading and one
button, **Adventures**, that takes you to your adventure list. Everything
else in this handbook starts from there.

## Signing out

Every screen's navigation drawer has a **Logout** entry. Using it ends your
session and returns you to the login screen.

> **Note:** Adventure Builder keeps one active session per account. Signing
> in again elsewhere doesn't forcibly kick out an existing session, but only
> one is treated as current — if things look odd, sign out and back in.
